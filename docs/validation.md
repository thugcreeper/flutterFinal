## Validation

Before completing any task:

Verify that:

* The code compiles without errors.
* Existing functionality is not broken.
* New features integrate correctly with the current architecture.
* State management remains consistent.
* API calls handle errors properly.
* Null safety is respected.
* No duplicate services, managers, or controllers are introduced.
* Existing project patterns are followed.

### Manual Verification First

Do not automatically generate test files unless explicitly requested.

Prioritize:

* Static analysis
* Code review
* Logical verification
* Manual testing checklist

When a feature is completed, provide a brief verification summary.
